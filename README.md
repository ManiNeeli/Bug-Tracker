# AI Bug Tracker

AI Bug Tracker is a full-stack bug management application built using React, Node.js, Express, and MongoDB.

## Features

- Create Bug Reports
- View All Bugs
- View Bug Details
- Update Bug Status
- Delete Bug Reports
- Dashboard Analytics
- MongoDB Database Integration
- REST API Architecture
- Gemini AI Integration (In Progress)

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### AI
- Google Gemini API

## Installation

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

## Environment Variables

Create:

```env

MONGO_URI=YOUR_MONGODB_URI

GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```
